## NWAV Editor PDF para Windows (64 bits)

Editor de PDF local y sin conexión.

### Cómo usarlo
1. Descarga `NWAV-Editor-PDF-…-windows-x64.zip`.
2. Descomprímelo en una carpeta tuya (no lo abras desde dentro del ZIP).
3. Haz doble clic en **«NWAV Editor PDF.cmd»**.

No hace falta instalar Java: va incluido. Si no abre, usa **«NWAV Editor PDF (diagnostico).cmd»** para ver el error.

### Herramientas
Editor completo; organizar (unir, dividir, rotar, recortar…); comprimir, OCR y reparar; convertir a PDF
(imágenes, escaneos, Office, HTML); convertir desde PDF (imagen, Word, Excel, PowerPoint, Markdown, PDF/A);
formularios, marca de agua, numeración y comparar; proteger, firma digital, redacción real y quitar metadatos.

### Opcional
- **Office a PDF:** instala [LibreOffice](https://www.libreoffice.org) (gratuito).
- **OCR:** funciona sin instalar nada. Si diera error, instala el «Microsoft Visual C++ Redistributable» (x64).

Tus datos (recientes, historial, preferencias) se guardan en `%LOCALAPPDATA%\NWAV Editor PDF`.
