## NWAV Editor PDF para Windows (64 bits)

Editor de PDF local y sin conexión.

### Cómo usarlo
**Instalador (recomendado):** descarga `NWAV-Editor-PDF-…-windows-x64-instalador.exe` y ábrelo. Se instala para tu
usuario (no pide permisos de administrador) y crea accesos en el menú Inicio y en el Escritorio.

**Portable:** descarga `NWAV-Editor-PDF-…-windows-x64.zip`, descomprímelo en una carpeta tuya (no lo abras desde
dentro del ZIP) y haz doble clic en **«NWAV Editor PDF.cmd»**.

No hace falta instalar Java: va incluido. Si no abre, usa **«NWAV Editor PDF (diagnostico).cmd»** para ver el error.

### Herramientas
Editor completo; organizar (unir, dividir, rotar, recortar…); comprimir, OCR y reparar; convertir a PDF
(imágenes y escaneos); convertir desde PDF (imagen, Word, Excel, PowerPoint, Markdown, PDF/A);
formularios, marca de agua y numeración; proteger o quitar contraseña.

### Opcional
- **OCR:** funciona sin instalar nada. Si diera error, instala el «Microsoft Visual C++ Redistributable» (x64).

Tus datos (recientes, historial, preferencias) se guardan en `%LOCALAPPDATA%\NWAV Editor PDF`.
